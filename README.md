# Flutter Login UI

A simple Flutter-based Login app that allows users to register and log in.

## Features
- **Just a login page and registration page**

## Installation

1. Install dependencies:
   ```sh
   flutter pub get
   ```
2. Run the app:
   ```sh
   flutter run
   ```
